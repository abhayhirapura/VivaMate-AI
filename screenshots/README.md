## How to capture

Use Chrome DevTools → `Ctrl+Shift+P` → "Capture screenshot" (full page).  
Or any screen capture tool. Recommended resolution: 1440×900+.

## Browser requirement

Use **Chrome or Edge** for screenshots — Safari and Firefox do not support SpeechRecognition.
